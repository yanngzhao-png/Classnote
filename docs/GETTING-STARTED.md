# 安装与配置

## 安装

需要 Apple 芯片 Mac 与 macOS 14+。从本仓库 Releases 下载 App 安装包，解压后将 Classnote.app 拖入“应用程序”。软件与源码授权见仓库根目录 LICENSE。

本版本仅为本地签名，未经过 Apple 公证。若系统阻止打开，先确认下载来源和 SHA-256 与官方 Release 一致；自行判断可信后，可按 [Apple 官方说明](https://support.apple.com/en-ie/102445)在系统设置 → 隐私与安全中处理“仍要打开”。不需要关闭系统整体安全保护。校验值只能检查文件是否一致，不等于 Apple 安全审核。

## AI 配置

设置 → 模型配置：输入自己的 OpenAI API Key，确认转录和文本模型是账户实际可用的模型，并分别检查连接。凭证由 App 存入 macOS 钥匙串，不要发给作者或写进 GitHub。

当前程序连接 OpenAI 官方接口；可修改模型名称，不提供任意服务商地址配置。预设名称不保证对每个账户可用；检查成功也不等于识别准确率保证。先试录短段，确认英文、中文和笔记均可正常生成后再用于课堂。使用费用由 API 服务商按账户与模型计费，App 显示的文本用量不是完整账单。

## 第一次课堂

1. 新建课程或选择已有课程；课表导入不是必需步骤。
2. 可选：在课程中准备有文字层的 PDF。当前一堂课使用一份 PDF，最多 25 MB、300 页、50 万提取字符。
3. 开始课堂，允许麦克风访问。只捕获麦克风，不提供系统音频捕获。
4. 可暂停、继续、缩小为播放器；字幕需要切段及网络处理，不是逐字零延迟。
5. 结束后等待尾段转录、翻译和笔记处理；确认结果后复制或导出。

没有课件也可以生成笔记。PPTX 请先导出带文字层的 PDF；扫描图片页目前不能识字。

## 常见问题

- 没有声音：检查系统麦克风权限、输入设备和 App 状态。
- 连接失败：检查网络、账户模型权限、额度与 App 中的错误提示。
- 断网：连接失败会暂停收音，恢复后按界面提示处理；已保存的失败音频段可重试。
- 意外退出：重启后已保存课堂可恢复查看，当前尚未提交的内存音频片段可能丢失。
- 字幕太小：播放器可调整字号 16–36，也可独立调整窗口尺寸。
- 不想配置 Notion：直接使用本地记录、复制和 Markdown 导出。
