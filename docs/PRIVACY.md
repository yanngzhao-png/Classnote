# 数据去向与保存边界

Classnote 本地保存课堂记录，但 AI 功能需要网络，不是完全离线处理。

| 内容 | 去向 |
|---|---|
| 麦克风音频 | 连续收音分段保存在本机，并发往已配置的 OpenAI 转录接口；安静片段也可能发送 |
| 英文原稿与上下文 | 发送给 OpenAI 用于翻译和生成笔记 |
| PDF | 本机提取文字并保留副本；生成关联笔记时将选用文字发往 OpenAI，不提供 OCR |
| Notion 归档 | 用户配置并触发后，将笔记和相关来源文字发送至所绑定的 Notion 页面；完整原稿可选 |
| API 与 Notion 凭证 | macOS 钥匙串 |
| 私人课表链接及配置 | 本机应用数据目录；导入或刷新订阅时访问用户提供的地址 |

课堂数据位于 `~/Library/Application Support/Classnote/Sessions/`。系统备份、第三方 API 和 Notion 自身的数据处理规则由相应服务决定。

暂停停止收音。录音按片段保存，崩溃可能丢失当前尚未提交的片段；连接失败会暂停捕获，不能依靠它在断网时独立持续录音。转译和 AI 笔记可能有误。

“最近删除”可恢复；永久清空需确认。本地删除不会删除 Notion 云端副本。发布问题反馈时请只使用合成数据或已获许可且去除私人信息的内容。
